# Document workflow

When creating a document, use this default workflow unless the user requests another format or explicitly wants Markdown only:

1. Write editable Markdown.
2. Convert Markdown to a polished PDF.
3. Verify PDF layout by rendering or reading the generated PDF.
4. Deliver both Markdown and PDF files.
5. Keep Markdown as the source of truth; regenerate PDF after content changes.

Use a reusable PDF template with a title page, table of contents when useful, page numbers, clickable links, readable spacing, and source notes. Choose LaTeX for academic or citation-heavy documents; choose Typst when it provides a faster equivalent; use a simpler Markdown-only output only when the user explicitly prefers it or PDF generation is unavailable.
